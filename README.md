# pingzhejian 平仄间

平仄间是一个专注于诗词创作与分享的在线平台，为诗词爱好者提供创作、交流和学习的空间。

## 功能特色

- **诗词创作**：提供优雅的编辑器，支持平仄格律校验
- **作品分享**：发布原创诗词，与同好交流切磋
- **诗词赏析**：品读经典诗词，学习名家作品
- **社区互动**：关注诗人，点赞评论，共建诗词社区

## 技术栈

- 前端：vue3 + TypeScript
- 后端：springboot
- 数据库：mysql

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```
